# code_practice

我的 C / C++ 学习练习代码（大一）。用 VS Code + MinGW 编写。

## 目录说明

| 目录 | 内容 |
|---|---|
| `.vscode/` | C 语言练习（数组、指针、字符串、函数、结构体、递归、排序等） |
| `.vscode_cpp/` | C++ 面向对象练习（按主题分子目录） |

## 编译方式

单个 `.cpp` 文件直接用 VS Code 的 C/C++ 任务编译；
多文件项目（含 `CMakeLists.txt`）在对应目录下按 CMake 流程构建。

> 仓库已通过 `.gitignore` 排除 `build/`、`*.exe`、`*.obj` 等编译产物。
